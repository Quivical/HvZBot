# HvZBot
A bot to assist with the facilitation and moderation of Humans versus Zombies. In order to use the bot, all you need to do is [invite it to your server](https://discord.com/api/oauth2/authorize?client_id=1040807329307840602&permissions=275146344464&scope=applications.commands%20bot), and get started with /guide or /help.

Originally conceived in conjunction with Goucher College's Humans versus Zombies Club, the bot is now being ~~actively~~ passively developed by Juliet Moss, most recently for her senior capstone project. Please join [HvZBot Hub](https://discord.gg/gT9276DgJP) for any questions, comments, or suggestions.

### Change Notes

The April 30th 2025 update, HvZBot 1.2.0, is a release that lays the groundwork for a web portal that allows players and mods to interact with the bot online, not just through Discord. When a sufficient number of the currently existing bot features are replicated, I will announce the release of HvZBot 2.0.0.
